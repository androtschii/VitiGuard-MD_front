# Компоненты

Компоненты разложены по уровням Atomic Design. Компонент может использовать только компоненты своего или более низкого уровня.

| Уровень     | Что лежит                                       | Примеры                       |
| ----------- | ----------------------------------------------- | ----------------------------- |
| `atoms`     | неделимые элементы интерфейса без бизнес-логики | кнопка, поле ввода, логотип   |
| `molecules` | небольшие сочетания атомов                      | поле формы с подписью, поиск  |
| `organisms` | самостоятельные блоки интерфейса                | шапка, форма входа, карта     |
| `templates` | каркасы страниц: расположение блоков без данных | центрированный экран, дашборд |

Страницы (`src/pages`) — это шаблоны, наполненные данными. Корень приложения, провайдеры и маршрутизация — в `src/app`.
