## Стратегия тестирования

| Уровень                  | Инструменты                   | Что проверяется                                  | Материал для отчёта                 |
| ------------------------ | ----------------------------- | ------------------------------------------------ | ----------------------------------- |
| Модульные и компонентные | Vitest, React Testing Library | отрисовка компонентов, валидация форм, состояние | скриншоты прогона, отчёт о покрытии |
| E2E                      | Playwright                    | сценарии: авторизация → карта → диагностика      | видео прохождения, trace-файлы      |

## Риски

| Риск                                              | Решение                                           |
| ------------------------------------------------- | ------------------------------------------------- |
| Плохое качество фото в поле (размытие, освещение) | проверка резкости на клиенте перед отправкой      |
| Нет интернета на виноградниках                    | PWA с квантованной ONNX-моделью прямо в браузере  |
| Много полигонов на карте                          | кластеризация и упрощение геометрии при отрисовке |
